# ⏱️ Discord 語音頻道時間記錄機器人

自動記錄成員進出語音頻道的時間戳記，並依頻道類別（📚 讀書、☕ 休息、💼 工作、⛏️ Minecraft）統計每天各待了多久。所有統計都能在文字頻道用斜線指令（`/`）查詢。

---

## ✨ 功能

- **自動記錄進出時間**：加入、離開、切換語音頻道都會被記下來，不需要手動打卡。
- **打卡面板**：不想進語音頻道的話，也可以按面板上的「工作室 / 讀書室 / 休息區」按鈕開始計時，面板上會即時顯示每一區有誰（包含在語音頻道裡的人）、待了多久。
- **頻道分類**：管理員可以把任何語音頻道指定為「讀書 / 休息 / 工作 / Minecraft」其中一類，同一類可以有多個頻道。
- **每日統計**：今天在各類頻道分別待了多久。
- **多日統計**：最近 N 天每天的明細，以及總計和日平均。
- **進出紀錄**：查看某一天每一次進出的時間點。
- **各頻道時間**：查看某一天在每個語音頻道各待了多久。
- **排行榜**：伺服器成員在某類頻道的時數排名。
- **每日排行榜公告**：每天在指定時間自動在指定頻道貼出前一天每個人讀書與工作的時數。
- **查詢權限**：可設定成大家都能查大家，或只能查自己（管理員除外）。
- **CSV 匯出**：匯出原始紀錄，可以用 Excel 或 Google 試算表做進一步分析。
- **跨日自動切割**：從 23:00 讀到隔天 01:30，會拆成前一天 1 小時、隔天 1.5 小時。
- **停機補償**：機器人重新啟動時會自動校正離線期間的進出狀態。

## 🧠 原理

### 1. 監聽語音狀態事件

Discord 在成員的語音狀態改變時，會透過 Gateway 送出 `VOICE_STATE_UPDATE` 事件。機器人在 `on_voice_state_update` 裡比較變化前後的頻道：

| 前 (`before.channel`) | 後 (`after.channel`) | 意義 | 機器人動作 |
|---|---|---|---|
| 無 | A | 加入 A | 若 A 有被追蹤，開始一段新時段 |
| A | 無 | 離開 A | 結束目前的時段 |
| A | B | 從 A 切換到 B | 結束 A 的時段；若 B 有被追蹤，開始新時段 |
| A | A | 靜音、拒聽、開鏡頭等 | 忽略 |

### 2. 資料儲存（SQLite）

資料存在單一個 SQLite 檔案（預設 `timerecord.db`），主要的表有：

- **`channel_map`**：記錄每個伺服器中「哪個語音頻道屬於哪一類」。
- **`sessions`**：每一次待在追蹤頻道的時段，內容是 `user_id`、`channel_id`、`category`、`join_ts`（進入時間）、`leave_ts`（離開時間，還沒離開則為 `NULL`）、`source`（`voice` 是語音頻道，`button` 是打卡面板）。時間一律存成 Unix timestamp（UTC 秒數）。
- **`panels`**：每個伺服器打卡面板訊息的位置，用來更新面板上的名單。
- **`meta`**：存放機器人「最後存活時間」等內部資訊。

類別是在**進入頻道當下**寫進時段的，所以之後就算重新設定頻道類別，也不會改到過去的歷史紀錄。

### 3. 統計計算

查詢時，先撈出與查詢區間有重疊的時段，把每段時間**依設定時區的午夜切開**，再分別加總到各日期、各類別。尚未結束的時段（人還在頻道裡）會以「現在」當作暫時的結束時間，所以統計是即時的。

### 4. 停機補償

機器人每 60 秒寫一次「最後存活時間」（心跳）。重新啟動時：

1. 找出所有尚未結束的時段，如果那個人**已經不在該頻道**，就用上次的最後存活時間當作離開時間（誤差最多 1 分鐘）。
2. 如果有人**現在已經在追蹤頻道裡**但沒有對應的時段，就從現在開始記錄。

> ⚠️ 機器人離線期間無法得知確切的進出時間，所以停機越久，這段期間的紀錄就越不精確。建議讓機器人 24 小時運作。

## 🚀 快速開始

本機器人需要**自行架設**：每個人用自己的 Bot Token 執行，資料存在自己的主機上。

1. 到 [Discord Developer Portal](https://discord.com/developers/applications) 建立 Bot、取得 Token，並邀請進伺服器。
2. 安裝並啟動：

   ```bash
   pip install -r requirements.txt
   cp .env.example .env    # Windows 用 copy；接著在 .env 填入 DISCORD_TOKEN
   python bot.py
   ```

3. 在 Discord 用 `/setup` 設定要追蹤的語音頻道。

📘 **完整步驟**（建立 Bot、邀請連結與權限、`.env` 設定、部署到 Railway、設定管理員權限）請看 [docs/setup.md](docs/setup.md)。

## 📖 使用方法

### 第一步：設定要追蹤的頻道（需要「管理伺服器」權限）

```
/setup channel:#讀書室 category:📚 讀書
/setup channel:#休息區 category:☕ 休息
/setup channel:#工作室 category:💼 工作
/setup channel:#Minecraft category:⛏️ Minecraft
```

設定完成後，之後有人進出這些頻道就會自動記錄。

### 指令一覽

| 指令 | 說明 | 範例 |
|---|---|---|
| `/setup channel category` | 把語音頻道設為某一類（管理員） | `/setup channel:#讀書室 category:📚 讀書` |
| `/unset channel` | 停止追蹤某頻道（管理員） | `/unset channel:#讀書室` |
| `/delete member date start end` | 刪除某成員在指定時間段的紀錄，例如忘記退出語音頻道（管理員，會先確認）。時間可用 `HH:MM` 或 `HH:MM:SS`，結束早於開始視為隔天 | `/delete member:@小明 date:2026-10-04 start:23:00 end:08:30` |
| `/privacy [mode]` | 設定能不能查詢別人的時間；不填則顯示目前設定（管理員） | `/privacy mode:🔒 私人` |
| `/report set channel [time]` | 每天在指定時間（預設 00:00）於該頻道公告前一天的排行榜；可選文字、公告或論壇頻道（管理員） | `/report set channel:#公告 time:08:00` |
| `/report off` | 關閉每日排行榜公告（管理員） | `/report off` |
| `/report preview [date]` | 預覽某天的排行榜（預設今天到目前為止），只有自己看得到（管理員） | `/report preview date:2026-10-14` |
| `/report post date` | 手動在公告頻道發佈某天（今天以前）的排行榜，用來補發或重發（管理員） | `/report post date:2026-10-14` |
| `/panel` | 在目前的頻道發佈打卡面板，舊的面板會被刪掉（管理員） | `/panel` |
| `/channels` | 列出目前追蹤中的頻道 | `/channels` |
| `/today [member]` | 今天各類別各待多久 | `/today` |
| `/stats [days] [member]` | 最近 N 天的明細、總計與日平均（預設 7 天，最多 186 天；超過 31 天時改為每週一行） | `/stats days:14` |
| `/log [date] [member]` | 某天每次進出的時間點（預設今天） | `/log date:2026-09-28` |
| `/channeltime [date] [member]` | 某天在每個語音頻道各待多久（預設今天） | `/channeltime date:2026-09-28` |
| `/status [member]` | 目前在哪個頻道或面板區域、已經待了多久 | `/status` |
| `/leaderboard [category] [days]` | 伺服器排行榜（預設讀書、7 天） | `/leaderboard category:⛏️ Minecraft days:30` |
| `/export [days] [member]` | 匯出 CSV 原始紀錄（只有自己看得到） | `/export days:90` |

`[member]` 可省略，省略時查詢的是自己。

### 查詢權限

管理員可以用 `/privacy` 決定成員能不能查詢別人的時間：

| 模式 | 說明 |
|---|---|
| 🌐 公開（預設） | 所有人都能用 `[member]` 查詢任何人 |
| 🔒 私人 | 一般成員只能查詢自己；擁有「管理伺服器」權限的人可以查詢所有人 |

私人模式會限制 `/today`、`/stats`、`/log`、`/channeltime`、`/status`、`/export` 查詢別人。`/leaderboard` 與每日排行榜公告不受影響；如果也想限制排行榜，可以在「伺服器設定 → 整合」把 `/leaderboard` 只開放給特定身分組（見 [docs/setup.md](docs/setup.md#5-設定管理員權限)）。

### 打卡面板

不想進語音頻道的話，可以改用按鈕打卡。管理員在想放面板的文字頻道執行：

```
/panel
```

機器人會發一則面板訊息：

```
⏱️ 打卡面板
💼 工作室（1）      📚 讀書室（3）          ☕ 休息區（0）
@小美 1 小時前      @小明 25 分鐘前         —
                    🎧 @阿凱 10 分鐘前
                    @小華 3 分鐘前
[💼 工作室] [📚 讀書室] [☕ 休息區] [🚪 離開]
```

- 按區域按鈕開始計時，換區直接按另一個，結束時按「離開」。
- 按鈕的回覆只有自己看得到；再按一次目前所在的區域，可以查看已經待了多久。
- 面板也會列出在追蹤中語音頻道裡的人，名字前面有 🎧；括號裡是那一區的總人數（按鈕打卡＋語音頻道）。⛏️ Minecraft 頻道的人不會出現在面板上。
- 面板上的「N 分鐘前」由 Discord 自動更新，不需要重新整理。有人進出語音頻道時，面板最多每 30 秒更新一次名單，所以可能會晚幾十秒才出現。
- 面板打卡和語音頻道一樣會計入 `/today`、`/stats`、`/leaderboard` 和每日排行榜（讀書室、工作室計入，休息區不計入）。
- **語音頻道優先**：人在追蹤中的語音頻道裡時不能用面板打卡；用面板打卡時進入追蹤中的語音頻道，面板的計時會自動結束，改用語音頻道計時，不會重複計算。
- 忘記按離開的話，超過 `PANEL_MAX_HOURS` 小時（預設 12）會自動以那個時間點結束計時。
- 機器人重新啟動後，舊面板上的按鈕仍然可以使用，打卡中的計時也會繼續。
- 每個伺服器只會有一個面板，重新執行 `/panel` 會把舊的面板刪掉。

**建議的擺放方式**：開一個專用的文字頻道（例如 `#打卡`），放在讀書室、工作室等語音頻道的同一個分類最上面，並把 `@everyone` 的「發送訊息」關掉，只保留「檢視頻道」和「讀取訊息歷史」。這樣面板永遠是頻道裡唯一一則訊息，不會被聊天訊息洗掉；按按鈕不需要發送訊息的權限，所以成員還是可以打卡。機器人本身要保留這個頻道的「發送訊息」「嵌入連結」權限。

### 每日排行榜公告

```
/report set channel:#公告 time:08:00
```

設定後，機器人每天在 `time`（依 `TIMEZONE`，格式 `HH:MM`，不填則為 00:00）會在該頻道貼出前一天的排行榜，只計算 📚 讀書與 💼 工作的時數（☕ 休息與 ⛏️ Minecraft 不計入），依兩者合計排序，並列出每個人各自的時數。如果機器人在公告時間剛好離線，會在當天稍後啟動時補發；如果發送時遇到 Discord 限速或暫時性的伺服器錯誤，會每 15 分鐘重試一次直到成功（權限不足等錯誤則不重試）。公告不會 @ 到任何人。

頻道可以選：

- **文字頻道**：直接發一則訊息。
- **公告頻道**：同上，其他伺服器也可以「追蹤」這個頻道。
- **論壇頻道**：每天開一篇標題為「🏆 MM/DD 每日排行榜」的新貼文，成員可以在每天的貼文底下留言。如果論壇開啟了「發文時需要標籤」，請先關閉。

想改公告時間或頻道，再執行一次 `/report set` 即可。

如果某天的公告漏發或內容有誤，可以先用 `/report preview date:YYYY-MM-DD` 確認內容，再用 `/report post date:YYYY-MM-DD` 重新發佈到公告頻道（論壇頻道會開一篇新貼文）。舊的公告不會被自動刪除，需要的話請手動刪掉。手動發佈不會影響每天的自動公告。

## ❓ 常見問題

**Q：輸入 `/` 後看不到指令？**
全域指令第一次同步可能需要一些時間才會出現。測試時可以在 `.env` 填入 `GUILD_ID`，指令就會立即出現在該伺服器。也可以試著重新開啟 Discord 客戶端。

**Q：電腦關機後資料會消失嗎？**
不會。資料都存在 `timerecord.db` 裡。不過機器人沒有執行的期間無法記錄進出。如果希望 24 小時記錄，可以把機器人放在雲端主機、樹莓派或 NAS 上執行。

**Q：log 出現 `429 Too Many Requests ... You are being blocked from accessing our API temporarily`？**
這是 Discord 暫時封鎖了主機的 IP，常發生在 Railway 這類多人共用 IP 的平台上（其他人的程式送出太多請求，大家一起被擋）。程式碼沒辦法解除封鎖，通常幾十分鐘到一小時內會自動解除。機器人登入時遇到這個錯誤會自己等待後重試（從 60 秒開始，每次加倍，最多 30 分鐘），不會一直重啟；每日排行榜也會自動補發。如果常常發生，可以考慮換到有獨立 IP 的主機（例如 VPS）。

**Q：可以新增其他類別嗎？**
可以。修改 `bot.py` 裡的 `CATEGORIES` 字典，例如加入 `"exercise": ("🏃", "運動")`，重新啟動後 `/setup` 就會出現新的選項。

**Q：想換時區，或把一天的分界改成凌晨 4 點？**
時區可以透過 `.env` 的 `TIMEZONE` 設定。一天的分界目前固定是午夜 00:00。
